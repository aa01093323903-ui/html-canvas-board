# 实测记录：用网页画板做一套演示（3 页 → 8 页）

日期：2026-11-05 · 画布尺寸：演示 16:9（1280 × 720）

这份记录是后面做「教程动画视频」的脚本素材。每一步都有截图（`shots/`）和当时的画板数据快照（`states/`，可以直接拿来还原画面）。

成品：[`成品.html`](成品.html)，双击用浏览器打开就能播放。按 → / 空格 / 点击翻页，F 全屏。

## 第 6 步　生成网页

正常用法：点右上角 **AI**（或 ⌘K）→「生成全部页面」，或在预览模式点「✨ 生成本页」。AI 会读整体说明、本页说明和每个模块的备注，一页一页写出来。

**这次的实际情况：** 还没配 API Key，所以由 Claude 读 `board.json`，按 `AGENTS.md` 的规则直接写了三页的网页源码（`output/parts/<页面id>.html`），效果和画板内置 AI 生成的一样，都会出现在预览和播放里。第一版源码存在 `parts-v1/`。

截图：`06a-生成-封面.jpg`、`06b-生成-三步流程.jpg`、`06c-生成-开始使用.jpg` · 数据：`states/06-三页已生成.json`

**看完预览后做的调整：**

1. 封面副标题折成了两行，最后一行只有「网页。」两个字 → 把文字区加宽到 640px
2. 第 2 页卡片下半截空着 → 编号放顶部，标题和说明压到卡片底部
3. 第 2 页中间卡片说明文字最后一个字掉到第二行 → 字号 17→16px

## 第 7 步　在预览里直接改字

切到 **预览**，点第 2 页副标题，直接在网页上把「不用写代码，也不用会设计。」改成「不用写代码，也不用会设计，**十分钟做完一套。**」。

- 改完自动保存回源码文件，不用重新生成
- 同时会弹出「告诉 AI 怎么改这里…」的小输入框，可以对这个元素提要求（需要 API Key）

截图：`07-预览里直接改字.jpg`

## 第二轮：扩展到 8 页

### 第 9 步　在第 2 页后面插入 5 页

在页面条选中第 2 页再点 **+**，新页会插在它后面。整体说明里的「3 页」改成「8 页」。

| 页 | 标题 | 本页说明 | 主要模块 |
|---|---|---|---|

| 4 | AI 助手 | 功能 2：⌘K 命令面板，四件事 AI 都能做 | 标题、命令面板（搜索栏）、4 张能力卡（自由框）、模型说明 |

| 6 | 用途：做网站 | 用途 1：同一套线框适配不同设备 | 标题、桌面 / 平板 / 手机三台设备（图片）、底部说明 |

截图：`11-画布编辑.jpg`、`12-AI助手.jpg`、`13-边看边改.jpg`、`14-用途-做网站.jpg`、`15-用途-代替PPT.jpg`

> 写备注的经验：「图片」模块不一定要放图片，备注里写「用 CSS 画一个…的动画」，生成出来就是会动的示意图（第 3、5 页都是这样做的）。

### 第 10 步　生成新增的 5 页

同样由 Claude 照 board.json 写源码（仍未配置 API Key）。每页的入场动画、循环演示动画都按「效果」备注实现：

- 第 3 页：模块从组件栏飞进画布 → 出现选中框和手柄 → 吸附到参考线 → 拉宽，7 秒一轮
- 第 4 页：命令面板里逐字打出「让 AI 排一页产品发布会的封面」
- 第 5 页：网页标题被选中、换成新文字 → 弹出 AI 小框 → 按钮变绿，9 秒一轮
- 第 6 页：三台设备依次升起，线框块轻轻闪动
- 第 7 页：右栏晚半拍出现，5 个 ✓ 逐行弹出

截图：`17a-生成-画布编辑.jpg`、`17c-生成-边看边改.jpg`、`17d-生成-做网站.jpg`、`17e-生成-代替PPT.jpg`、`16-八页全部生成.jpg`

**预览后修改：**

2. 第 4 页卡片文字最后一个字单独一行、卡片下半截空 → 字号 16→15px，图标置顶、文字压底
3. 第 5 页演示窗口下半部分空 → 网页内容整体下移
