用途一：设计你想要的网站

手机、平板、桌面都能画。画好线框，跟 AI 说一句「照画板做」，整站就出来了。

画板会把布局存成 board.json，Claude Code、Codex 这类编程助手也能直接读懂。

用途二：用网页代替 PPT

你现在看的这套演示，就是用网页画板做出来的。

传统 PPT

  • 动画死板，只有几种模板
  • 发给别人，对方要装软件
  • 改个字，要找到原文件
  • 放不了能点的交互
  • 换个屏幕比例就变形

网页画板

  • CSS 动画，想怎么动就怎么动
  • 发一个链接，浏览器就能看
  • 预览里点字，直接改
  • 按钮、复制、表单都能用
  • 自动缩放，适配任何屏幕

播放：← → 翻页 · F 全屏 · Esc 退出 · 支持 PageUp/PageDown 翻页笔
